Melo Chat Lite - Profile Post Update

Changes:
- Own Profile posts can be edited.
- Own Profile posts can be deleted (with confirmation).
- Removed "Who can see this post" from composer.
- Removed Add Location from composer.
- New and edited posts are always saved as Public.
- Editing a post also clears any old location from that post.
- Profile post date displays as DD Month YYYY, e.g. 01 December 2026.
- Existing photo upload remains supported (up to 8 images).

Install:
Copy/overlay this ZIP into the project root.
No new SQL migration is required for this update, provided the previous social-post migration has already been run.
