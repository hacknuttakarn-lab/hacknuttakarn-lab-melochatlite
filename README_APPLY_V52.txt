Melo Chat Lite V52 overlay

แก้ไข:
1. Home/Recommended แสดงเฉพาะโปรไฟล์ที่กรอกข้อมูลบังคับครบ
2. โปรไฟล์ที่ไม่มีชื่อจริงจะไม่ถูกสร้างเป็นการ์ด "Melo User"
3. ตรวจข้อมูลหลัก: first/last name, gender, DOB, height, nationality, education, relationship status, looking_for, sexual orientations, lifestyle และรูปโปรไฟล์
4. รองรับ lifestyle key ทั้ง pet/pets, drink/drinking, smoke/smoking เพื่อเข้ากับข้อมูลเดิม

วิธีใช้: วางไฟล์ใน ZIP ทับโปรเจกต์เดิม แล้วรัน npm run dev
